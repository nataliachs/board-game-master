# Lantern Trail — Original ingestion demo

This fictional example was written for this repository. It is not a commercial game's rulebook. You may use, modify, and redistribute this example under CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/).

## Setup

Place five paper spaces in a row. Give each player one token and put all tokens on the first space.

Put three spare markers beside the trail. Choose a starting player together.

<!-- page: 2 -->
## Taking a turn

Move your token forward one space. If the destination contains another token, move to the next empty space instead.

When your token reaches the last space, take one spare marker and return your token to the first space.

## Ending the demo

When the spare markers run out, finish the current turn and end the demo. Count collected markers to compare results.

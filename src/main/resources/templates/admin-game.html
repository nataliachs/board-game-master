2. Setup steps

What players do with the real box before playing. Fill one card per step; empty cards are ignored. Save to get five more blank cards.

Saving publishes a new set of steps for new sessions.

3. Lessons

Short lessons in teaching order. Tick which teaching styles show each lesson, and choose the one lesson where players stop to set up the table.

Save setup steps first if you want a lesson to start guided setup.

4. Rules for questions optional

Upload rules you have permission to use as a .txt or .md file, then index them so the Game Master can answer questions with citations. Indexing needs an embedding provider and may cost money.
